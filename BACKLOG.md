# Product Backlog

| ID | User Story | Priorité |

| US1 | En tant qu'utilisateur, je veux voir une page avec un formulaire et une liste, afin d'utiliser l'application facilement. | Haute |
| US2 | En tant qu'utilisateur, je veux ajouter une tâche, afin de ne pas l'oublier. | Haute |

| US7 | En tant qu'utilisateur, je veux que mes tâches soient sauvegardées, afin de les retrouver après avoir fermé la page. | Basse |
