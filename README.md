# Gestionnaire de tâches

Application web simple de gestion de tâches, réalisée en équipe dans le cadre du module Approche Agile.

## Équipe
Sofia, Ibtissam, Meryem et Souhail

## Fonctionnalités
- Ajouter une tâche
- Marquer une tâche comme terminée
- Supprimer une tâche
- Filtrer : toutes, à faire, terminées
- Compteur de tâches restantes
- Sauvegarde automatique dans le navigateur

## Lancer le projet
Ouvrir le fichier index.html dans un navigateur.
